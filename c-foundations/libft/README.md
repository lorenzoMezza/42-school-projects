# Libft

My own C standard library, reused in every later C project.

| Language / tools | 42 Common Core | Status |
|---|---|---|
| C | Core | Code coming soon |

## What it is

A reimplementation of a large part of the C standard library (strings, memory, conversions) plus linked lists and extra helpers, written from scratch and compiled into a static library.

## What it shows

- Pointers and manual memory management
- Writing a reusable static library with a Makefile
- Edge cases and undefined behaviour of libc

# Python Modules 00-10

Thirteen modules (00 to 10, plus two bis modules) that take Python from the basics to professional practice.

| Language / tools | 42 Common Core | Status |
|---|---|---|
| Python 3, mypy, flake8, Pydantic | Circle 2 | Code coming soon |

## What it is

A series of exercise modules, each on one area of the language. Every exercise is typed and passes mypy and flake8.

## What it shows

- The language end to end, see the table below
- Type hints checked with mypy, style with flake8
- Packaging, virtual environments and configuration

## The modules

| Module | Topic | What it covers |
|---|---|---|
| [module-00](module-00) | Basics | Syntax, variables, expressions, functions and control flow |
| [module-01](module-01) | First programs | Classes and objects to manage data |
| [module-02](module-02) | Errors | Exceptions and resilient data pipelines |
| [module-03](module-03) | Data structures | Lists, dictionaries, sets, tuples and comprehensions |
| [module-04](module-04) | Files | File operations, streams and context managers |
| [module-05](module-05) | Polymorphism | Abstract classes, method overriding and subtype polymorphism |
| [module-05-bis](module-05-bis) | Packaging | Virtual environments, dependencies, configuration through the environment and Python packages |
| [module-06](module-06) | Imports | Packages, absolute and relative imports, circular dependencies |
| [module-06-bis](module-06-bis) | Design patterns | Abstract base classes, structural typing, factories and strategies |
| [module-07](module-07) | Interfaces | Design patterns with abstract classes, a modular card system |
| [module-08](module-08) | Data pipelines | Virtual environments, package management and a first data pipeline |
| [module-09](module-09) | Validation | Data models and validation with Pydantic |
| [module-10](module-10) | Functional Python | Higher-order functions, decorators and lambdas |

# Fly-in

Route a fleet of drones through a network of zones in as few turns as possible.

## What it is

A routing system that moves many drones through connected zones with capacity and movement constraints, minimising the number of simulation turns.

## What it shows

- Graph search and multi-agent path finding
- Simulation under constraints
- Parsing and visualising a network

A complete, playable Pac-Man game.

| Language / tools | 42 Common Core | Status |
|---|---|---|

## What it is

A playable arcade game in object-oriented Python, with a simple graphical library, ghosts with their own behaviour and levels loaded from files.

## What it shows

- Object-oriented game architecture
- Game loop, input and rendering
- Robust error handling (no tracebacks for bad input)

# 42 Common Core

My path through the Common Core at [42](https://www.42network.org/), a peer-to-peer programming school with no teachers and no lectures: every project is a specification to implement on my own, then reviewed and tested by other students before it counts.

Every validated project is in this repository, in its own folder, with its original commit history from 42's Git server. Each folder has a README explaining what the project does and how to run it.

# Python Modules 00-10

Eleven short modules that take Python from the first `print` to typed, validated, packaged code. Each module is a set of small exercises (`ex0`, `ex1`, …) around one topic.

| Module | Topic | Exercises |
|---|---|---|
| [00](module-00) | Basics: variables, input, conditions, loops, recursion | 8 |
| [01](module-01) | Classes and objects: constructors, encapsulation, inheritance | 7 |
| [02](module-02) | Exceptions: raising, catching, custom errors, `finally` | 5 |
| [03](module-03) | Collections: lists, tuples, sets, dicts, generators, comprehensions | 7 |
| [04](module-04) | Files and streams: reading, writing, `with`, standard streams | 4 |
| [05](module-05) | Abstract classes and polymorphism (`abc`): a data-processing pipeline | 3 |
| [06](module-06) | Modules and packages: imports, `__init__.py`, circular imports | 1 package |
| [07](module-07) | Design patterns: abstract factory, capabilities, strategy | 3 |
| [08](module-08) | Environments: virtual envs, dependencies, `.env` configuration | 3 |
| [09](module-09) | Data validation with Pydantic | 3 |
| [10](module-10) | Functional programming: lambdas, higher-order functions, closures, `functools`, decorators | 5 |

Every exercise runs on its own, for example:

```sh
python3 module-10/ex4/decorator_mastery.py
```

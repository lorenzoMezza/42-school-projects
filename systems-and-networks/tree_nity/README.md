## What it is

A message broker for asynchronous, event-driven communication: producers publish to topics, consumers subscribe, and stored messages can be filtered efficiently.

## What it shows

- Message queues and event-driven design
- Concurrency (goroutines or threads)
- Efficient storage and prefix matching, unit tests

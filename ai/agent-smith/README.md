# Agent Smith

An AI agent that solves coding challenges on its own.

| Language / tools | 42 Common Core | Status |
|---|---|---|

## What it is

An agent framework that reasons about a coding problem, writes code, runs it in a sandbox and iterates until the solution works, using the Model Context Protocol (MCP) for its tools.

## What it shows

- Code agents and tool use
- Model Context Protocol (MCP)
- Safe, sandboxed code execution with Docker

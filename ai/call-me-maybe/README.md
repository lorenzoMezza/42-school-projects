# Call Me Maybe

Teach a language model to answer with function calls a program can run.

| Language / tools | 42 Common Core | Status |
|---|---|---|
| Python 3, LLM | Circle 3 | Code coming soon |

## What it is

A tool that turns requests in natural language into structured function calls with typed arguments, using a small local language model.

## What it shows

- LLM function calling
- Constraining model output to a schema
- Validating and running structured results

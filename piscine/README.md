# C Piscine

The four-week selection pool to get into 42: Shell and C from scratch, one module a day, with weekend team projects (rushes) and weekly exams. Every exercise is checked by peers and by an automatic grader, which stops at the first failing exercise.

| Module | Topic | Grade |
|---|---|---|
| [Shell 00](shell-00) | Files, permissions, archives, `ls`, Git, SSH keys | 50 |
| [Shell 01](shell-01) | Shell scripts: groups, `find`, counting files, MAC addresses, odd filenames | 40 |
| [C 00](c-00) | First C programs: `write`, printing characters and numbers | 50 |
| [C 01](c-01) | Pointers: swap, division and modulo through pointers | 50 |
| [C 02](c-02) | Strings: copying, character classes, changing case | 55 |
| [C 03](c-03) | Strings: compare, concatenate, search (`strcmp`, `strcat`, `strstr`, `strlcat`) | 50 |
| [C 04](c-04) | `strlen`, `putnbr`, `atoi`, number bases | 70 |
| [C 05](c-05) | Recursion and math: factorial, power, Fibonacci, square root, primes | 80 |
| [C 06](c-06) | Command-line arguments: print, reverse and sort `argv` | 100 |
| [C 07](c-07) | Memory allocation: `strdup`, ranges, `strjoin` | 60 |
| [C 08](c-08) | Header files, macros, structs | 100 |
| [Rush 00](rush-00) | Team project: draw rectangles of characters in five styles | 116 |
| [Rush 02](rush-02) | Team project: write a number in words from a dictionary file | 0 |

Rushes were done in teams, so their history includes my teammates' commits. C 09 and the exams have no published code.
